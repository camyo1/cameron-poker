# Cameron's Poker

A mobile-friendly Texas Hold'em practice game with virtual chips, a computer opponent, betting actions, showdown hand evaluation, and an expandable hand-ranking guide.

## Play immediately
Open `index.html` in a modern browser. The game works offline once the files are on your device.

## Install as an app on iPhone
1. Put the contents of this folder on an HTTPS web host (for example, a static-site host).
2. Open the hosted site in Safari on your iPhone.
3. Tap Share → Add to Home Screen → Add.
4. Launch Cameron's Poker from the Home Screen. The service worker caches the app for offline use after the first visit.

## Android
Open the hosted HTTPS site in Chrome, then use the browser menu → Install app / Add to Home screen.

This package is a Progressive Web App, not an App Store-signed native iOS/Android binary. Chips are virtual; no real-money gambling or online multiplayer is included.
